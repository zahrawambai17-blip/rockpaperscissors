# rockpaperscissors
name: FATIMAH ZAHRAU WAMBAI
pathway: intro to generative ai (biginner)

TOOLS USEDED
IDLE (python 3.12)

i created a rock, paper, scissor game that is continuous unless the user says stop.

Parameters
1. rock beats scissors
2. paper beats rock
3. scissors beats paper
4. when both AI and user pick the same choice, it is a draw

HOW TO RUN
1. in your command promtpt navigate to where file is saved using 'cd'
2. run using: 'python rockpaperscissors.py'
